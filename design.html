Why it’s built this way

Every significant decision on my action RPG is written down as an Architecture Decision Record: the problem, the options I weighed, what I chose, and what it cost. These are the ones that shaped the game most.

Key decisions

Technical design is how the engine stays deterministic and moddable. Game design is how the game should feel to play, build and trade.

How the design changed

Decisions aren’t edited in place. Reversing one takes a new record that supersedes the old one, so the history of each change stays readable.
